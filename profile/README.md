# FOCUS — 언론 보도 비평 기사 작성 시스템

여러 언론사가 같은 사안을 어떻게 다르게 다뤘는지 비교하는 **비평 기사를 기자가 AI와 함께 쓰는 도구**입니다.
미디어스 인턴 프로젝트로 개발했습니다. (2026. 7. ~ 8.)

## 기자의 작업 순서

```
최근 사설 훑기 → 발췌 담기 → 발췌를 묶어 이슈 생성 → 초안 작성 → 검토 → 발행
```

기자가 기사를 읽다가 매체마다 다르게 다룬 지점을 발견하면, 근거가 되는 대목을 직접 읽고
발췌해 담습니다. 시스템은 그 발췌만을 근거로 초안을 만들고, 검토 단계에서 인용 진위를
원문과 대조합니다.

## 설계 원칙

- **저작권·약관 준수를 구조로 강제** — 기사 본문을 자동 수집하거나 저장하지 않습니다.
  검색은 결과를 저장 없이 그대로 보여주는 통과 조회이고, 기사 작성의 근거는 기자가 직접
  읽고 고른 발췌뿐입니다. 시스템이 자동으로 접근·저장하는 타사 데이터는 0건입니다.
- **인용은 종(從), 비평이 주(主)** — 발췌 길이 상한을 코드 관문으로 강제해 인용이
  본문을 넘어서지 못하게 합니다.
- **판단은 사람에게** — 무엇을 인용할지, 어떤 이슈로 묶을지, 발행할지는 전부 기자가
  결정합니다. AI는 초안 작성과 검토 보조만 맡습니다.

## 구성

| 영역 | 내용 |
|---|---|
| 백엔드 | FastAPI · SQLAlchemy 2.0 · PostgreSQL · Alembic |
| 프론트 | React · TypeScript · Vite |
| 배포·감시 | Docker Compose · nginx · certbot · Prometheus · Grafana |
| AI | 비평 초안 생성 2단(프레이밍 → 근거 기반 작성) + 코드 기반 검토 판정 |

전체 코드와 개발 기록은 비공개 저장소 `FOCUS-App`에 있습니다.
